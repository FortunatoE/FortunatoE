# Emmanuel Fortunato

### Software Development · Data Engineering · Process Automation

Transformo dados, processos complexos e necessidades de negócio em soluções digitais utilizáveis, rastreáveis e orientadas à decisão.

Atuo como **Analista de Planejamento Pleno** no agronegócio, conectando informações operacionais, ERP, planilhas e interfaces gerenciais. Minha experiência combina análise de dados, Business Intelligence, desenvolvimento de aplicações e automação de processos.

## Áreas de atuação

- **Desenvolvimento de software** — aplicações web, APIs, regras de negócio e interfaces operacionais.
- **Dados e BI** — integração, transformação, modelagem e visualização de dados para apoio à decisão.
- **Automação de processos** — rotinas administrativas e operacionais mais consistentes, rastreáveis e eficientes.
